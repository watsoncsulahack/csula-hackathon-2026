# AI Frame Staging

Place generated image frames here for animation stitching.

## Suggested sets
- `serp-flow/` — flow-of-information frames
- `serp-ux/` — app UI concept frames
- `serp-db/` — database/secure connection visuals

Frames should be named sequentially, e.g.:
- `frame_0001.png`
- `frame_0002.png`
- ...
