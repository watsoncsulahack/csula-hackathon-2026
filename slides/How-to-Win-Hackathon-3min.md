# How to Win a Hackathon (3-Minute Pitch Version)

## Timing Formula (180s total)
- 0:00-0:45 — Background / Problem (25%)
- 0:45-2:15 — Demo (50%)
- 2:15-3:00 — Impact + Close (25%)

## Slide Plan
1. Title + one-line value proposition (10s)
2. The problem in today’s flow (35s)
3. Our solution architecture (20s)
4. Live demo walk-through (75s)
5. Why it matters + ask + close (40s)

## 3-minute delivery rules
- Show only what judges need to believe execution is real.
- If something is mocked, say it clearly and pivot to the measurable value.
- Keep one backup line if demo fails.

## Backup close line
"Even with mocked integrations, we proved the core decision logic and user flow in under 14 hours, and we have a clear path to production integration."
