# Identity / KYC Wireframe Concepts

## Screen K1 — Onboarding + Privacy Notice
- Headline: "Create account"
- Required consent checkboxes:
  - Data use for demo only
  - Privacy policy acknowledgment
  - No real emergency dispatch from this prototype
- CTA: Continue

## Screen K2 — Identity Basics
- Full name
- Organization
- Role (Patient, EMS, Hospital, Insurer, Admin)
- Email + phone
- CTA: Verify

## Screen K3 — Verification Step
- OTP code entry
- Optional document upload (future)
- Status chip: Pending / Verified / Failed

## Screen K4 — Access Scope Confirmation
- Assigned permissions summary
- Data visibility scope
- Last login + session security note

## Screen K5 — Audit and Consent Log
- Timeline table of consents and verification events
- Export consent receipt
