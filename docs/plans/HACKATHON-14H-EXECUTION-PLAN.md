# 14-Hour Hackathon Execution Plan (Judge-Impact First)

## Goal
Ship a compelling end-to-end concept demo with clear value, even if some automation is mocked.

## Hour-by-hour
- **H1-H2**: Lock storyboard + judge script + success metrics
- **H3-H5**: Build Android dummy app screens (no backend)
- **H6-H7**: Implement local mock data wiring in app
- **H8-H9**: Build simple backend stub (optional) / or prerecorded API traces
- **H10**: Validate 3 scenarios end-to-end demo flow
- **H11**: Polish visuals and talking points
- **H12**: Record fallback demo video
- **H13**: Final deck pass + team rehearsal
- **H14**: Submission packaging

## Must-have for judges
- One strong problem statement
- One clear system flow
- One concrete recommendation output with explanation
- One believable implementation roadmap

## Nice-to-have (skip if time is tight)
- Live DB writes
- Real API integrations
- Full auth and permissions model

## Decision rule
If a task cannot be demoed in 5 minutes, defer it.
